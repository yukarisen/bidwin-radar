# 必赢 · 标讯雷达

**说一句话，找到你能投的标。**

标讯雷达是面向投标人员的 AI 标讯助手。你只需用日常语言描述需求，它就能从全国公开招投标信息中，找出与你业务相关、且符合企业资质的项目，并把冗长的公告整理成便于决策的要点。

无需学习新系统，安装到你正在使用的 AI 助手中即可使用。

---

## 核心能力

### 🔍 一句话找标
用日常语言描述需求即可，主题、地区、时间、预算、采购类型会自动识别。结果已去除重复和不相关的内容，已结束的项目自动排除，只呈现值得关注的机会。

### ✅ 资质智能匹配
结合企业的注册资本、成立年限、参保人数、注册地、资质证书与业绩情况，逐项对照招标门槛，清楚标出哪些项目可以投、还差哪些条件。企业信息在使用过程中逐步补充，无需一次性填写。

### 📋 公告要点提炼
报名截止与倒计时、预算、采购内容、资质与业绩要求、联系方式、风险提示，集中呈现。所有信息均来自公告原文。

### ⏰ 每日定时推送
设定关注方向后，每天在你指定的时间自动推送新发布、且符合企业资质的标讯，条件可随时调整。

### 🔒 数据本地保存
企业信息与推送条件仅保存在你的电脑上，不会上传。

## 三步开始使用

标讯雷达是一个「技能（Skill）」，安装到你正在使用的 AI 助手（Agent）中即可使用。

### 第 1 步：请 AI 助手安装

在 AI 助手的对话框中，**复制并发送下面这句话**：

```
请帮我安装这个技能：https://github.com/yukarisen/bidwin-radar
```

AI 助手会自动下载、安装并检查运行环境。如果中途电脑弹窗询问是否允许安装，请点击「是 / 安装 / 允许」。

> 如果 AI 助手提示无法下载：
> 1. 用浏览器打开上面的链接，在 GitHub 页面点击「Code」按钮 →「Download ZIP」，将压缩包下载到电脑上
> 2. 把压缩包发给 AI 助手，并发送：「请帮我安装这个压缩包里的技能」

### 第 2 步：发送你的 key

技术人员会单独向你提供一串 key。请在对话框中发送：

```
这是我的标讯雷达 key：（在这里粘贴 key）
```

看到「已配置好（尾号 XXXX）」即表示配置完成。

### 第 3 步：填写公司的 4 项基本情况（可跳过）

配置完成后，AI 助手会请你提供：

1. 成立时间（精确到年或年月即可）
2. 注册资本（万元）
3. 参保人数（大约多少人缴纳社保）
4. 注册地（省或城市）

一条消息回复即可，例如：「2019 年 6 月成立，注册资本 500 万，30 人，杭州」。
也可以回复「跳过」，之后随时发送「填写我的资质」补充。

随后，AI 助手会询问你主要关注哪些方向的标讯。告诉它即可，例如「汽车品牌传播、新媒体运营」，它会为你设置每天的定时推送，推送时间由你决定（详见下方「每日推送」）。

## 使用方法

像平时说话一样提出需求即可，例如：

- 帮我找北京最近一个月数字人的标
- 有没有短视频代运营的招标？
- 查一下这个季度浙江的宣传片采购，50 万以上的
- 最近两周上海、杭州的展会搭建项目，不要设备采购

AI 助手会列出筛选后的结果，每条都有编号：

- **回复编号**（如「3」）→ 查看报名截止、联系方式、公告要点与资质对照
- **回复「更多」** → 查看下一批结果
- **回复「按资质筛一下」** → 只看符合企业资质的项目

**使用提示**
- 结果过多，或大部分与需求无关时，AI 助手会说明情况，并建议换一种说法、限定地区或设置金额下限。按建议回复一句即可。
- 没有找到结果时，可以尝试招标公告中常用的说法，例如「宣传片」也可以说「专题片」「形象片」。
- 想查看中标结果、了解竞争对手，可以直接说「看看最近的中标结果」。

## 如何高效查询

以下几个使用习惯，能让 AI 助手更快找到真正相关的标讯，结果也更准确。

- **想每天了解新标讯，请使用每日推送**：发送「每天帮我推送 XX 的标」即可。每日推送只推送新发布的标讯，不会重复出现看过的内容。**请不要自行新建定时任务并填写「帮我查一下 XX」**，这样每天都会把近一个月的标讯重新查询一遍，结果中大多是之前看过的内容。
- **一次说清一个方向**：例如「汽车品牌传播、新媒体、KOL 投放的标」，用一句话说完即可。AI 助手会把相近的说法合在一起查询，结果更集中，不需要列出一长串词语让它逐个查询。
- **使用招标公告中的常用说法，避免过于宽泛的词**：「品牌」「设计」「活动」这类词，一个月可能对应几十万条公告，能看到的只有最近几个小时的，而且大多与需求无关。建议说得具体一些（如「品牌推广服务」「汽车品牌」）；不确定怎么说时，可以请 AI 助手推荐。
- **AI 助手提示结果过多或不相关时，请按它的建议调整**：换一种说法或缩小范围，比逐页往后翻能更快找到相关项目。
- **想看哪一条，回复编号即可**：无需让它把所有结果都查一遍报名截止日期，每日推送会自动排除已截止的标讯。

**用量参考**：标讯雷达按次数计算用量，各项操作的用量如下。

| 操作 | 用量 |
|---|---|
| 查询一次 | 1 次（相同条件半小时内再次查询，不重复计算） |
| 查看一条详情 | 2 次（已查看过的再次查看，不重复计算） |
| 按资质筛选一条 | 1～2 次（已过报名截止的为 1 次） |
| 每日推送 | 通常每天不超过几十次 |

## 资质匹配

首次安装时填写的 4 项基本情况，会用于对照每条标讯的门槛。资质证书与业绩无需提前填写：遇到公告中有相关要求时，AI 助手会向你确认一次，之后自动判断。

企业情况有变化时，直接告诉 AI 助手即可，例如：

- 看看我的资质档案
- 我们拿到广播电视节目制作经营许可证了
- 注册资本改成 1000 万
- 推送里不符合资质的也给我看

## 每日推送

如果希望每天自动收到新标讯，请发送：

```
每天帮我推送北京数字人相关的标
```

也可以在查询结束后，AI 助手询问「要把这次的条件设成每日推送吗？」时，回复「好」。

AI 助手会先与你确认推送条件，再询问每天几点推送（如果暂时没有想好，可先设为早上 9 点，之后随时可以修改），然后完成设置。每次推送只查询最近 3 天、只推送之前没有推送过的新标讯，已过报名截止的会自动排除；填写过资质信息的，只推送符合门槛的项目。

- 查看：「我现在推送的是什么？」
- 修改：「推送再加上天津」「推送时间改成 8 点」
- 取消：「不要推数字人了」「推送全部停掉」
- 最多可同时设置 3 组推送条件。关注方向较宽时（例如「汽车营销相关的都要」），AI 助手会按业务帮你分成几组，每组包含多种常用说法。

> 如果 AI 助手表示无法自行创建定时任务：请在 AI 助手中新建一个定时任务，运行时间设为你希望的时间（例如每天 9:00），任务内容**一字不改**地填写：
> ```
> 用标讯雷达推送今天的新标
> ```
> 推送哪些内容，由你告诉 AI 助手的推送条件决定，无需写进任务里。**请不要把任务内容写成「帮我查一下 XX 的标」**，否则每天都会重新查询近一个月的标讯，结果中大多是之前看过的内容。
>
> 注意：定时推送需要电脑保持开机，AI 助手保持运行。

## 常见问题

**Q：提示「key 无效或已过期」「服务暂时不可用」怎么办？**
请联系技术人员。

**Q：数据来自哪里？**
必赢标讯库，覆盖全国公开招投标信息。

**Q：资质匹配的依据是什么？**
依据公告原文和你提供的企业信息逐项对照，结论附有原文出处，便于核对。企业情况有变化时告诉 AI 助手即可，匹配结果会随之更新。

**Q：我的 key、推送条件和资质档案安全吗？**
它们只保存在你自己的电脑上，不会上传，也不会写入 AI 助手的记忆。查看过的公告也会在电脑上保存一份，再次查看时无需重新查询，打开更快。请不要把 key 转发给他人。

**Q：换了电脑或 AI 助手怎么办？**
重新完成第 1～3 步即可。推送条件和资质档案只保存在原来的电脑上，在新电脑上重新告诉 AI 助手一次就可以。

**Q：如何卸载？**
请见下方「卸载」。

## 卸载

在对话框中发送：

```
请卸载标讯雷达技能
```

AI 助手会先询问你：**是否保留 key、推送条件和资质档案**（保留后，今后重新安装可以直接使用）。确认后，它会：

1. 关闭每日推送的定时任务
2. 删除标讯雷达技能
3. 按你的选择删除或保留 key、推送条件和资质档案

看到「标讯雷达已卸载」即表示卸载完成。

> 如果 AI 助手未能自动完成，可以手动卸载：
> 1. 在 AI 助手的定时任务列表中，删除内容为「用标讯雷达推送今天的新标」的任务
> 2. 在 AI 助手的技能管理中，删除「必赢 · 标讯雷达」
> 3. 如果不再保留 key、推送条件和资质档案：删除用户目录下的 `.bidwin` 文件夹（Mac：`~/.bidwin`；Windows：`C:\Users\你的用户名\.bidwin`）
>
> Python 是通用的运行环境，其他软件也可能在使用，卸载标讯雷达时**无需**卸载 Python。

## 安装说明（写给 AI 助手）

> 以下内容写给安装本技能的 Agent。用户发来本仓库链接要求安装时，按此执行。

1. 下载仓库压缩包：`https://github.com/yukarisen/bidwin-radar/archive/refs/heads/main.zip`（用户已经直接发来压缩包的，跳过这一步）
2. 解压后得到 `bidwin-radar-main` 文件夹，**重命名为 `bidwin-radar`**，放进你（当前 Agent）加载技能的目录。不确定目录在哪，就按你所在平台的技能安装方式处理。
3. 确认 `bidwin-radar/SKILL.md` 与 `bidwin-radar/scripts/radar.py` 都存在。
4. 按 `references/setup.md` 完成首次环境检查（确认本机有 Python 3.8+，没有就安装）。
5. 请用户发送标讯雷达 key，按 `SKILL.md`「写入 key」完成配置。
6. 按 `SKILL.md`「资质问卷」问用户 4 项基本情况（用户可跳过）。

**卸载**：用户要求卸载时，按 `SKILL.md`「七、卸载」执行。

**更新**：用户要求更新本技能时，重新下载压缩包，用新文件整体覆盖技能目录即可。`~/.bidwin/` 里的 key、推送条件和资质档案在技能目录之外，不受影响，**不要删除**。

不要修改本技能内的任何文件。
