# 必赢 · 标讯雷达

**说一句话，找到你能投的标。**

标讯雷达是面向投标团队的 AI 标讯助手。用日常语言描述需求，即可从全国公开招投标信息中找到与你业务相关、且符合企业资质的项目，并将冗长的公告提炼为可直接决策的要点。

无需学习新系统，装进你正在使用的 AI 助手即可开始。

---

## 核心能力

### 🔍 一句话找标
用日常语言描述需求，主题、地区、时间、预算、采购类型自动识别。结果经过去重与降噪，已结束的项目自动排除，只呈现真正值得关注的机会。

### ✅ 资质智能匹配
结合企业的注册资本、成立年限、参保人数、注册地、资质证书与业绩储备，逐项对照招标门槛，清楚标出可投项目与具体缺口。企业档案在使用中逐步完善，无需一次性录入。

### 📋 公告要点提炼
报名截止与倒计时、预算、采购内容、资质与业绩要求、联系方式、风险提示，一屏看全。所有信息均来自公告原文。

### ⏰ 每日精准推送
设定关注方向，每天早上自动推送新发布、且符合企业资质的标讯，随时调整。

### 🔒 数据本地保存
企业档案与订阅条件仅保存在本机，不上传。

## 3 步开始用

标讯雷达是一个「技能（Skill）」，装进你正在使用的 AI 助手（Agent）里就能用。

### 第 1 步：让 AI 助手安装

在 AI 助手的对话框里，**复制发送下面这句话**：

```
请帮我安装这个技能：https://github.com/yukarisen/bidwin-radar
```

它会自动下载、安装并检查运行环境。中途如果电脑弹窗询问是否允许安装，点「是 / 安装 / 允许」即可。

> 如果它提示无法下载：
> 1. 用浏览器打开上面的链接，在 GitHub 页面上点「Code」按钮 →「Download ZIP」，把压缩包下载到电脑上
> 2. 把这个压缩包发给 AI 助手，并说：「请帮我安装这个压缩包里的技能」

### 第 2 步：发送你的 key

技术人员会单独发给你一串 key。在对话框里发送：

```
这是我的标讯雷达 key：（把 key 粘贴在这里）
```

看到「已配置好（尾号 XXXX）」就配置完成了。

### 第 3 步：告诉它公司的 4 项基本情况（可跳过）

配置好 key 后，它会问你：

1. 成立时间（到年或年月就行）
2. 注册资本（万元）
3. 参保人数（大概多少人交社保）
4. 注册地（省或城市）

一条消息回复即可，例如「2019 年 6 月成立，注册资本 500 万，30 人，杭州」。
也可以回复「跳过」，之后说「填写我的资质」随时补充。

接着它会问你主要想盯什么方向的标。告诉它，比如「汽车品牌传播、新媒体运营」，它会帮你设好每天早上的推送（见下方「每日推送」）。

## 怎么用

直接用平时说话的方式问，例如：

- 帮我找北京最近一个月数字人的标
- 有没有短视频代运营的招标？
- 查一下这个季度浙江的宣传片采购，50 万以上的
- 最近两周上海、杭州的展会搭建项目，不要设备采购

它会列出筛好的结果，每条带编号：

- **回复编号**（如「3」）→ 查看报名截止、联系方式、公告要点与资质对照
- **回复「更多」** → 继续看下一批
- **回复「按资质筛一下」** → 只看符合企业资质的项目

**小技巧**
- 结果太多、或者大多不相关时，它会告诉你，并建议换个说法、限定地区或设金额下限，照着回一句就行
- 没找到时，试试招标里常用的叫法，比如「宣传片」也可以说「专题片」「形象片」
- 想看中标结果、了解竞争对手，直接说「看看最近的中标结果」

## 怎么用最省次数

每次查询、看详情都会用掉次数。下面几个习惯能省不少，查得也更准：

- **想每天看新标，用每日推送**：说一句「每天帮我推送 XX 的标」就行。**不要自己新建定时任务、写「帮我查一下 XX」**，那样每天都会把近一个月重新查一遍，花的次数是推送的好几倍，看到的也大多是前几天看过的。
- **一次说清一个方向**：比如「汽车品牌传播、新媒体、KOL 投放的标」，一句话说完。不要列一长串单词让它逐个查。
- **用招标里的叫法，少用单独的泛词**：「品牌」「设计」「活动」这类词一个月有几十万条，能看到的只是最新几个小时，大多不相关。可以说得具体些（如「品牌推广服务」「汽车品牌」），不确定叫法就让它推荐。
- **它说噪音大、结果太多时，照它的建议调**：换个说法或缩小范围，比一页页往后翻更省也更准。
- **想看哪条，回编号**：不用让它把所有结果都查一遍截止日期，推送会自动去掉已截止的标。

大概会用掉多少次：

| 操作 | 次数 |
|---|---|
| 查一次标 | 1 次（同样的条件半小时内再查不花） |
| 看一条详情 | 2 次（看过的再看不花） |
| 按资质筛一条 | 1~2 次（已截止的 1 次） |
| 每日推送 | 通常每天几十次以内 |

## 资质匹配

首次安装时填写的 4 项基本信息，会用于对照每条标讯的门槛。资质证书与业绩要求无需提前录入：遇到相关要求时，它会向你确认一次，之后自动判断。

企业情况有变化时，直接告诉它即可：

- 看看我的资质档案
- 我们拿到广播电视节目制作经营许可证了
- 注册资本改成 1000 万
- 推送里不符合资质的也给我看

## 每日推送

想每天早上自动收到新标，跟它说一句：

```
每天帮我推送北京数字人相关的标
```

或者查完一次标后，它问「要把这次的条件设成每日推送吗？」时回「好」。

它会跟你确认条件，然后设置好每天 9 点的定时推送。每次只查最近 3 天、只推没推过的新标，已过报名截止的自动去掉；填写过资质的，只推送符合门槛的项目。

- 查看：「我现在推送的是什么？」
- 修改：「推送再加上天津」「推送时间改成 8 点」
- 取消：「不要推数字人了」「推送全部停掉」
- 最多同时盯 3 组条件。方向比较宽时（比如「汽车营销相关的都要」），它会按业务帮你分成几组，每组包含多种常见说法

> 如果它说不能自己创建定时任务：在 AI 助手里新建一个**每天 9:00** 运行的定时任务，任务内容**一字不改**地填：
> ```
> 用标讯雷达推送今天的新标
> ```
> 推送什么由你跟它说的条件决定，不用写进任务里。**不要把任务内容写成「帮我查一下 XX 的标」**，那样每天都会重新查近一个月，很费次数。
>
> 注意：定时推送需要电脑开着、AI 助手在运行。

## 常见问题

**Q：提示「key 无效或已过期」「服务暂时不可用」？**
请联系技术人员。

**Q：数据从哪里来？**
必赢标讯库，覆盖全国公开招投标信息。

**Q：资质匹配的依据是什么？**
依据公告原文与你提供的企业信息逐项对照，结论附原文出处，便于核对。企业情况有变化时告诉它即可，匹配结果随之更新。

**Q：我的 key、推送条件和资质档案安全吗？**
都只保存在你自己的电脑上，不上传，也不会写进 AI 助手的记忆。看过的公告也会在本机留一份，再看时不重复花次数。请不要把 key 转发给他人。

**Q：换了电脑或换了 AI 助手怎么办？**
重新做一遍第 1～3 步即可。推送条件和资质档案只存在原来那台电脑上，在新电脑上重新跟它说一次就行。

**Q：怎么卸载？**
见下方「卸载」。

## 卸载

在对话框里发送：

```
请卸载标讯雷达技能
```

它会先问你：**要不要保留 key、推送条件和资质档案**（保留的话，以后重新安装可以直接用）。确认后它会：

1. 关掉每日推送的定时任务
2. 删除标讯雷达技能
3. 按你的选择删除或保留 key、推送条件和资质档案

看到「标讯雷达已卸载」就完成了。

> 如果它没能自己处理，可以手动卸载：
> 1. 在 AI 助手的定时任务列表里，删除内容为「用标讯雷达推送今天的新标」的任务
> 2. 在 AI 助手的技能管理里删除「必赢 · 标讯雷达」
> 3. 如果不再保留 key、推送条件和资质档案：删除用户目录下的 `.bidwin` 文件夹（Mac：`~/.bidwin`；Windows：`C:\Users\你的用户名\.bidwin`）
>
> Python 是通用运行环境，其他软件也可能在用，卸载标讯雷达时**不需要**卸载它。

## 安装说明（写给 AI 助手）

> 以下内容写给安装本技能的 Agent。用户发来本仓库链接要求安装时，按此执行。

1. 下载仓库压缩包：`https://github.com/yukarisen/bidwin-radar/archive/refs/heads/main.zip`（用户已经直接发来压缩包的，跳过这一步）
2. 解压后得到 `bidwin-radar-main` 文件夹，**重命名为 `bidwin-radar`**，放进你（当前 Agent）加载技能的目录。不确定目录在哪，就按你所在平台的技能安装方式处理。
3. 确认 `bidwin-radar/SKILL.md` 与 `bidwin-radar/scripts/radar.py` 都存在。
4. 按 `references/setup.md` 完成首次环境检查（确认本机有 Python 3.8+，没有就安装）。
5. 请用户发送标讯雷达 key，按 `SKILL.md`「写入 key」完成配置。
6. 按 `SKILL.md`「资质问卷」问用户 4 项基本情况（用户可跳过）。

**卸载**：用户要求卸载时，按 `SKILL.md`「七、卸载」执行。

**更新**：用户要求更新本技能时，重新下载压缩包，用新文件整体覆盖技能目录即可。`~/.bidwin/` 里的 key、推送条件和资质档案在技能目录之外，不受影响，**不要删除**。

不要修改本技能内的任何文件。
